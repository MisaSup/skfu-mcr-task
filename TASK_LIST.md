# Список заданий

1. **`task/01`** — Сайт-анкета на свободную тему: сверстать страницу с формой.
 *Технологии:* HTML, CSS

2. **`task/HC-04`** — Игра по CSS: Flexbox Froggy, практика `flexbox`.
 *Технологии:* CSS (flexbox)

3. **`task/JS-01`** — Задачи по JavaScript для знакомства с языком.
 *Технологии:* JavaScript, Node.js

4. **`task/TS-02`** — Упражнения по TypeScript: интерфейсы, union/narrowing, дженерики, классы.
 *Технологии:* TypeScript, `tsc`, Node.js

5. **`task/CAT-01`**, **`task/CAT-01-demo`** — Асинхронная загрузка данных из публичного API и минимальный UI.
 *Технологии:* TypeScript, esbuild, `fetch`/`async-await`, npm, Node.js

6. **`task/EXPO-00`** — Знакомство с Expo: подготовка окружения для React Native.
 *Технологии:* React Native, Expo

> Ветки `*-demo` — это готовые шаблоны-заготовки для соответствующих заданий.
